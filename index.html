Reference Library

Coordinates

Latitude is north/south, −90° to +90°. Longitude is east/west, −180° to +180°. Coordinates are angular positions on Earth.

Observations

Retain type, value, time, location, source and relevant quality/confidence information. Missing is not automatically zero.

Confidence

Model confidence describes confidence in a classification, not automatically the physical probability that the classification is true.

Earth observation

Satellite products may describe areas rather than single points. Quality flags and processing versions can affect comparability.

Time & freshness

Observed time and retrieval/download time are different. Cached information may describe an earlier observation.

APIs

API results can be paginated, empty, incomplete or unavailable. HTTP 200 does not guarantee useful observations.

Offline data

Offline systems should distinguish local evidence from information requiring a live connection and retain timestamps/provenance.

Change calculations

Relative change from a non-zero reference is (new − reference) / reference × 100.
